Este proyecto contiene el desarrollo completo de la Evaluación 1 (E1) - Calidad y Preparación de Datos, la cual consiste en implementar un proceso reproducible de diagnóstico, análisis exploratorio de datos (EDA), tratamiento de inconsistencias y preparación de datos sobre un dataset de rendimiento académico estudiantil (rendimiento_academico_evaluacion.csv).

El objetivo principal es resolver los problemas de calidad de datos bajo el principio GIGO (Garbage In, Garbage Out) para transformar un conjunto de datos crudo y "ruidoso" en un dataset estandarizado, limpio y optimizado (rendimiento_academico_limpio.csv), listo para entrenar modelos predictivos de Machine Learning.
